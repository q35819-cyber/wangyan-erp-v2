# 网研ERP开源商品采集助手 0.4.44

本插件基于活动版0.4.43中筛选的自有采集及ERP桥接代码，整理为社区版0.4.44。未包含第三方私有API和打包素材，不能保证与内部活动版所有功能相同。

## 五步安装

1. 在 Edge/Chrome 下载或克隆整个 GitHub 开源仓库，解压并保留目录结构。
2. 先在本机启动并登录网研ERP：http://127.0.0.1:8765。端口固定为8765，本插件只连接本机。
3. Edge打开 edge://extensions/（Chrome打开 chrome://extensions/），启用开发人员模式。
4. 选择「加载解压缩的扩展」，指向本仓库 extensions/wyerp-collector/ 文件夹（其中直接包含 manifest.json）。
5. 将网研ERP开源采集助手固定到工具栏，并刷新商品详情页。

## 采集商品

- 打开 1688 商品详情页 detail.1688.com/offer/... 或 Ozon 商品页 www.ozon.ru/product/...。
- 自行登录平台、完成验证码，等待商品、SKU、价格、详情图片实际加载。
- 点击页面的「网研ERP 采集商品」，也可尝试扩展工具栏入口。
- 返回 ERP 的「采集箱」，确认已写入商品、SKU、图片和价格。失败必须按页面错误排查，不应假定成功。
- 类目、库存、尺寸、报价等来源信息必须人工核对。店铺 API、分析数据仅限当前账号依法有权访问的内容。

## 权限、安全与限制

本版源自原项目活动插件中筛选的自有源码，未附带第三方ERP程序的打包JS/CSS、私有API客户端、会话Token读取模块或商业账号数据。改名只适用于本项目自己的变量、标识和界面文案；不代表重新授权第三方代码。

插件只接受已有的本机ERP会话和 CSRF 校验；没有登录/无权限时应拒绝采集保存。
不自动同步订单、库存，不启用插件心跳、不上传用户账号密码，不绕过Ozon Premium权限。

浏览器侧栏、Seller分析与旧天眼逻辑部分依赖站点结构、账号授权及平台规则；可能在新版网页中失效。仅手动采集属于主要开源目标。
本插件版本0.4.44不等于活动插件0.4.43的全部第三方集成功能，后者另有经审查未发布的私有/第三方集成功能。

## 排错

- 插件加载失败：确认选中的是含 manifest.json 的单层目录，在浏览器扩展页查看具体错误。
- 采集按钮不出现：确认是支持的商品详情URL，刷新并等待页面数据加载。
- ERP连接失败：直接在同一浏览器打开 http://127.0.0.1:8765 并登录。
- 保存403或CSRF失败：刷新ERP会话并核实当前租户的采集箱权限。
- 类目匹配失败：1688第三方类目目录未随项目发布，需自行提供合法参考数据并人工核对。
- 需要其它商品平台：必须另行开发适配，不能假设所有网站都支持。
