新增AI配置

支持的能力

新增 AI 平台

参考 ToonFlow 的“平台配置 + 模型用途分配”：先填写平台的兼容接口，再指定 ERP 用于文本还是图片。所有字段都能修改，没有强制绑定 GRS AI。

仅支持符合 OpenAI Chat Completions / Images 接口协议的服务。视频 API 不同服务商差异很大，本版暂不接通，避免配置成功却无法调用。连接测试可能不扣费；功能测试或生成可能由供应商计费。

新增自定义供应商适配器

参考 ToonFlow 的可编程供应商体系。输入平台名称、模型、API密钥和请求/响应映射程序；适配器由ERP受控HTTP引擎执行，不允许任意JS/TS运行。无需改主程序、无需重启。

可定义POST/GET、平台内的接口路径、Bearer或X-API-Key认证、JSON请求体变量、响应字段、图片轮询。不能直接读取磁盘、运行任意TypeScript或向其他域名发送请求。功能测试或生成可能产生供应商费用。

快捷导入 AI 平台

支持三种入口：① 粘贴 JSON / 纯数据配置代码；② 粘贴 OpenAI 兼容的 cURL 请求；③ 从本机选择 .json 文件。一次最多导入 10 个模型，导入后可随时编辑。

配置代码仅支持 export default 后接严格 JSON，不执行用户编写的 TypeScript/JavaScript 函数。特殊平台协议尚不能通过代码直接扩展。密钥仅留在当前输入框内，提交后按现有机制加密保存；导入成功会清除输入。
