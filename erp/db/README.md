# 网研ERP PostgreSQL 数据库（社区版）

本项目唯一的业务数据库为 PostgreSQL。数据库初始化、迁移与安全加固需要由部署者在自己的隔离环境中完成。

## 迁移文件与操作入口

- 数据库 Schema 版本文件位于 erp/db/migrations/。
- 核对 erp/package.json 中的 db:status、db:migrate 和 db:verify 命令。
- 先用全新的独立数据库完成初始化和回归测试；不要连接、复制或覆盖任何已有真实商家数据库。
- 数据库连接通过环境变量或独立 Secret 文件提供。不要把账号密码、备份文件、业务数据库、买家信息、店铺 API 凭据或加密密钥提交到 Git。
- 生产部署前独立完成 PostgreSQL 角色权限、租户隔离、事务一致性、备份恢复、加密、审计及迁移回滚测试。

本社区版本不提供原开发者的数据库备份、账号、店铺资料、公司资料、迁移验收记录或运营数据。旧内部数据库运行证据及本机备份路径不属于开源内容。
