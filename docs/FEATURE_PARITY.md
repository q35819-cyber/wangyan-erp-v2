# 网研 ERP 开源插件功能保留及缺口

对比基线：源私有Release中的活动插件0.4.43与公开自有源码插件0.4.44。版本号代表本次整理，非所有原私有功能的等价保证。

## 已保留代码与已执行测试

- 手动从1688商品详情页采集商品基本信息、SKU、报价和媒体的解析逻辑。
- Ozon商品公开页内容解析。
- 浏览器插件将手动采集信息交给已经登录的本机ERP，通过同源/CSRF验证写入采集箱。
- 购物币种、单位、物流描述与安全URL边界检查。
- ERP登录失效、重复采集和异常页面的错误处理。
- 独立的插件界面及Manifest V3权限限制。
- 只读的Seller统计和天眼历史兼容代码，须有平台合法权限。
- 离线单元和浏览器消息模拟测试42/42 PASS，不是实站采集成功报告。

## 与原活动插件不一致的部分

| 功能/依赖 | 当前处理 | 换机后的影响 |
| --- | --- | --- |
| 活动插件中的第三方私有API模块 | 不公开 | 原第三方私有指标与会话联动不可直接复用 |
| 大型第三方打包的页面脚本与样式 | 不公开 | 不保留原第三方完整界面与弹窗 |
| 1688第三方类目树 | 不公开原始文件 | 类目匹配可能需要人工或合法数据源 |
| Ozon佣金参考表 | 不公开原始文件 | 佣金推算和类目定价需要配置合法新版数据 |
| 原插件活动版独有新增功能 | 没有确认全部迁移 | 需要逐项对照真实操作，不能默认全功能保留 |
| 第三方会员/Premium能力 | 不绕过权限 | 不可使用没有被平台授予的高级指标 |
| 自动订单同步/插件心跳 | 永久禁用 | 手动API同步按原业务规则执行 |

## 换机后必须真实验收

打开支持的1688/Ozon商品页 → 确认插件触发 → 查看采集预览 → 提交至本机ERP → 登录身份和租户匹配 → 数据库中确实保存记录 → ERP采集箱显示SKU、媒体、价格。

缺失或失败项要进入新社区版修复计划，不能直接下载第三方专有插件并更改名字复原，也不能在没有对照验证的情况下声称0.4.44完整替代私有活动插件。
