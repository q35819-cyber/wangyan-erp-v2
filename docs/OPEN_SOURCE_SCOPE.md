# 网研ERP开源范围

此版本是经筛选的统一Release开源快照，不是开发者整块磁盘目录或原私有工作区镜像。

公开内容：
- erp/：ERP服务端、前端页面、数据库结构迁移、通用配置范例及必需的应用资源。
- extensions/wyerp-collector/：从自有活动插件源码中整理的浏览器采集助手0.4.44；支持手动采集与本机ERP采集箱桥接，未完成真实平台端到端测试。
- docs/：换机安装、配置、用户操作、插件安装、版权边界说明。
- 第三方开源依赖许可证说明（参见 THIRD_PARTY_NOTICES.md）。

未公开内容：
- 真实数据库、备份、日志、店铺/公司/客户信息、邮件配置、密钥和账号会话。
- 私人合同、商业模板、微信二维码、个人联系方式、开发内部验收报告。
- 测试夹具、开发电脑诊断脚本与内部任务记录。
- 毛子ERP插件安装包及其第三方打包CSS/JS、私有API/Token模块。
- 未纳入统一Release的其它分支，以及需另外授权的类目目录、佣金表等参考数据。

不能把全部功能视作开箱即用。插件0.4.44不包含历史内部活动插件所有第三方联动功能；服务器首次数据库初始化、管理员创建与生产安全必须单独验收。本仓库不授权任何Ozon/1688商标、会员数据或第三方服务的使用权。
