# 网研ERP 开源范围

本版本是统一 Release 的审慎公开快照，不是原私有项目工作目录镜像。

纳入：erp/ 中的业务服务、前端、必要静态资产、测试脚本、数据库迁移与示例配置。

排除：
- 真实数据库、备份、日志、授权码、密码、订单和其他客户隐私
- 个人联系方式及二维码、私人合同文件和内部测试验收报告
- output/ 下构建包、从第三方软件获取的资源和代码
- extensions/ 浏览器采集插件及其测试：因与第三方网页内部行为耦合，来源和再授权权利尚待独立核实
- 未进入统一 Release 的独立开发分支和旧工作区临时修改

功能影响：不包含浏览器采集插件，原采集链路并非即装即用；请勿宣称这是全功能可商用安装包。

本仓库不授予 Ozon、1688 或其他平台的 API 调用、商标、付费权益或第三方内容版权。生产部署须独立审查。

补充：公开版已清空历史应用公告记录（erp/data/notices.json）；邮件服务配置没有预置发件人、收件人、授权码；不提供原开发者数据库、真实店铺 ID 或公司资料。
