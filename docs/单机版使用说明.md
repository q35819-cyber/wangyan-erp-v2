# 网研ERP 单机版使用说明

> 适用版本：Windows 64 位单机安装版 `preview29`。这是一份供用户使用的说明，不是源码部署教程。单机预览版尚未完成所有第三方平台的正式环境验收。

## 一、安装与首次启动

1. 获取 `WyerpERP-Community-Setup-v0.1.0-preview29.exe`，双击运行，按照安装向导完成安装。安装 Windows 服务可能需要管理员权限。
2. 安装包**已经内置** ERP 前后端、Node.js 运行环境、PostgreSQL 数据库和网研ERP采集插件文件，无需客户另行安装 Node.js 或 PostgreSQL。
3. 安装后打开 **WyerpERP-Manager（网研ERP单机管理器）**。单机管理器可启动、重启、停止后台，也可打开 ERP 网页。
4. 点击「启动后台」，确认启动成功，再点击「打开 ERP 网页」。实际本机访问地址和端口以管理器显示为准，不必自己填写固定端口。
5. 关闭管理器**不会**自动停止 ERP 服务；需要关闭时，请点击「关闭后台服务」。

**首次登录（仅全新安装）：** 用户名 `admin`，初始密码 `123456`，同时填写页面显示的图形验证码。登录后应尽快修改密码。已有数据的升级安装沿用原账号密码，不会自动改回初始密码。

## 二、首次安装浏览器采集插件

采集插件文件已随 EXE 安装，**不需要另外下载插件包**。但未上架浏览器商店的扩展不能由安装器静默启用：

1. 打开管理器，点击「**查看 / 安装采集插件**」。
2. 点击「检查插件文件」，确认文件完整。
3. 点击「打开 Edge 扩展页」或「打开 Chrome 扩展页」。
4. 在浏览器扩展管理页打开「开发人员模式」，点击「加载解压缩的扩展」。
5. 使用管理器里的「复制插件路径」选中安装目录下的 `collector\wyerp-collector` 文件夹，确认加载。
6. 固定浏览器工具栏上的网研ERP采集助手图标。

完成后，登录 ERP，在 1688/Ozon 商品页面**手动采集**，返回「采集箱」确认商品是否真正入库。仅有插件图标不等于采集和入库成功。

## 三、主要功能怎么用

| 功能 | 入口与操作 |
| --- | --- |
| 店铺 | 打开「店铺列表」，新增自己的 Ozon 店铺，填写合法持有的店铺 ID/API 凭据，保存后核对店铺是否出现。 |
| 采集箱 | 通过浏览器插件手动采集商品，在 ERP 采集箱检查标题、图片、价格、SKU、重量和来源信息。 |
| 新增/编辑商品 | 从采集箱选择商品，检查标题、类目、属性、标签、图片、价格与俄语内容，保存草稿或按需要人工刊登。 |
| SKU/变体与组合 | 核对颜色、尺寸、货号、每个变体的成本、图片、重量和库存；组合商品另核对父项/子项数量及汇总成本。 |
| 在线商品 | 在「在线商品」「上架记录」选择店铺查看状态。变更上架状态前核对真实平台权限和返回结果。 |
| 订单 | 在「我的订单」按店铺和时间筛选，通过允许的**人工触发**官方 API 流程获取订单，再查看任务进度和结果。 |
| 订单统计 | 先核对店铺、时间范围、数据同步时间，再看统计；缓存数据不一定实时。 |
| 定价与利润 | 配置采购、国内/国际物流、佣金、广告、收单、提现等成本与费率，使用定价及利润工具复核结果。 |

**注意：** 自动订单同步和插件心跳功能不启用；不要把预览版当作自动无人值守同步工具。发布商品、拉取订单、使用第三方平台接口均需有效账号及对应权限。

## 四、自定义 AI 服务

1. 进入「**AI配置 → AI服务配置**」，点击「新增AI配置」。
2. 填入自己使用的平台名称、HTTPS API 地址、模型 ID 和 API Key；按实际用途配置文本或图片能力。
3. 也可通过「代码 / cURL / 文件导入」提取配置，保存前**人工检查**接口地址和模型名称。
4. 对非标准接口，可使用「自定义供应商适配器」填写**受限 JSON** 请求/响应映射；它不能直接执行任意 JavaScript/TypeScript。
5. 保存后先使用少量数据试用，留意模型权限、额度和第三方计费。

密钥应只通过 ERP 的配置页面录入，不要写入文档、截图、公开仓库或发送给其他人。真实 AI 视频生成功能不应视为已支持。

## 五、备份、升级与常见问题

- **升级前备份：** 重要业务数据保存在本机 PostgreSQL，不要把浏览器缓存当作正式备份；不要随意删除旧安装的数据目录、数据库和密钥。
- **打不开 ERP / 显示服务未就绪：** 在管理器查看服务状态，点击启动或重启，检查端口是否被其他程序占用。
- **登录失败：** 核对管理员账号、密码、图形验证码；旧版本升级不是默认密码 `123456`。
- **采集失败：** 检查插件是否启用、是否已登录正确的本机 ERP 地址、商品页面是否加载完全，以及采集箱是否有真实新增记录。
- **AI 失败：** 检查 API 地址、模型、密钥、授权、账户余额及第三方接口错误，谨慎重复发起收费任务。
- **关闭窗口后服务还在：** 属于正常设计，必须在管理器点击「关闭后台服务」。
- **不用的 SaaS 功能：** 单机基础版不要求会员开通、邮件注册或 AI 豆充值。

## 六、适用边界

本说明对应单机预览版。已完成隔离安装、基础登录和部分业务页面/接口测试；不代表所有 Ozon/1688 真实采集、刊登、同步、全部财务场景或第三方收费 AI 接口均已通过生产环境验收。请使用自己的账号、真实数据和平台授权逐项核验。

**对外交付：只需要发送单机版 EXE 安装文件。** 这份说明保存在代码仓库，客户不需要另外安装运行环境。
