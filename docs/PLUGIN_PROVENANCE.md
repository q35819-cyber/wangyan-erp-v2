# 插件版权来源与开源边界

本仓库 extensions/wyerp-collector/ 社区版本0.4.44，是从网研ERP活动插件0.4.43目录中筛选自有JS/CSS/HTML，保留原采集和ERP保存桥接功能后，独立整理并调整名称的开源版本。此目录不是第三方插件安装包。

明确没有纳入活动目录下的 maozi-private.js、maozi-session.js、content-scripts/content.js、content-scripts/content.css、chunks/、assets/ 和第三方参考插件本体；不提供私有API、原作者帐号、Cookie、会话Token或商业权益。

将这次筛选的20个JS/CSS/HTML文件与本机毛子ERP 3.3.5插件内容抽样比较，共检测1862个长度350字符的代码窗口，没有出现完全相同的连续片段。此结果只是一项有限风险检查，不是法律版权鉴定，也不能证明不存在短代码借鉴或其他版权问题。

自有代码中使用了中性的第三方页面参考命名；页面DOM兼容和第三方已有渲染指标需要使用者确保符合法律、账号授权和平台使用条款。修改标识本身并不构成对第三方软件源码的授权。

旧内部插件包含更多私人API集成及打包代码，故此公开社区版本虽然保留采集和桥接主要功能，但不承诺与原活动插件所有私有功能完全一致。当前离线单元测试42/42通过；真实浏览器平台采集及数据库端到端部署尚需使用者复测。
