# 网研ERP开源版功能使用指南

此版本为历史内测源码，不是已验收的商用服务。账号权限不同，显示的菜单也不同。

登录：先按 docs/CONFIGURATION.md 搭建全新数据库、管理员并配置服务，在本机打开 http://127.0.0.1:8765。
店铺：左侧「店铺列表」配置自己合法持有的Ozon店铺与平台API凭据，不提供原作者的店铺账号。
商品：安装 docs/EXTENSION_INSTALL.md 所述浏览器采集插件，到1688/Ozon商品页手动采集，再进入ERP「采集箱」确认商品、SKU、媒体和报价。编辑并发布前人工核对Ozon类目、物流、重量、尺寸、币种。
在线：左侧「在线商品」「上架记录」用于查看和管理商品；外部平台操作必须符合API权限。
订单：左侧「我的订单」「订单统计」基于自己导入或人工发起官方API同步的订单资料；原版自动订单同步和插件心跳永久废止。
费用：使用「定价设置」「定价工具」「利润计算器」「物流配置」之前，应自行录入合法真实的成本和费率；默认资料与历史参考表未必完整。
分析：数据大屏、分析及Seller统计依赖自己店铺的合法数据，部分功能需外部类目树/佣金表；没有数据时不能将空结果误认为测试通过。
账号：子账号、权限、会员、AI豆、邮件和监控等需按部署环境自行配置，部分模块尚未验证可用于公网。
安全：绝不上传数据库、店铺凭据、个人邮箱、合同、私人联系方式或敏感文件；生产部署前另做完整功能与安全复测。
